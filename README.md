## 原生 IP、家宽 IP、双 ISP，到底差在哪

这三个词经常被混着用，但对 TikTok 来说差别很实在。

**原生 IP** 指 IP 归属地就是菲律宾本地，没有经过隧道转播，平台识别出来的地区是菲律宾。**家宽 IP（住宅 IP）** 指这个 IP 在 ISP 数据库里的类型是"家庭宽带"，不是机房服务器。**双 ISP** 是同一台机器绑了两个运营商的网络，IP 质量更高，被判定为异常的概率更低。

三样叠在一起，就是"菲律宾原生家宽双 ISP IP"。TikTok 的风控会把机房 IP 标成 Datacenter IP，风险分拉高，轻则限流，重则封号。这是行业里普遍的说法，不是 TikTok 官方公布的规则，但你从实际封号案例里能看出这个规律。

有一点要提醒：市面上不少标着"菲律宾 IP"的产品，实际只是做了虚拟定位，服务器物理上托管在菲律宾境外。买之前查两件事，IP 归属地是不是菲律宾，ISP 类型是不是住宅网络。WePC 这款的第三方检测结果两项都对得上，但你自己拿到机器后仍建议用 ping0.cc 之类工具复核一次。
